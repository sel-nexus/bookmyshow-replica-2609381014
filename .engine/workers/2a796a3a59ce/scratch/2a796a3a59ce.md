### Features
- F1 Auth: mobile number + hardcoded OTP 1234 login (FR-AUTH-01..05)
- F2 Movies catalog: 3 seeded movies Paradise, Bloody Romeo, OG2 (FR-CAT-01..03)
- F3 Theatres: 3 seeded theatres Sandhya 70mm, Sudharsham 70mm, Allu Cinemas (FR-THEATRE-01..04)

- F6 Booking + success screen: "Congratulations!", movie/theatre/seats shown (FR-BOOK-01..04)
- F7 DB seeding on startup (FR-SEED-01)

### API endpoints (PRD-specified)
- POST /api/auth/login — accepts mobile number, returns success (FR-AUTH-04)
- POST /api/auth/verify — accepts mobile + OTP 1234, returns session token/JWT (FR-AUTH-05, FR-AUTH-03)
- GET /api/movies — returns catalog (FR-CAT-03)
- GET /api/theatres — returns theatres (FR-THEATRE-04)
- POST /api/bookings — accepts booking (movie, theatre, seats, payment method), saves to DB, returns confirmation ID (FR-BOOK-02)

### User flows / pages (frontend routes)
- login (mobile) -> login/otp -> movies (dashboard) -> movies/[id] (theatres) -> seats -> payment -> success
- Success screen: "Congratulations!" + movie + theatre + seats A1,A2,A3

### Data models
- Movie: title, poster placeholder
- Theatre: name, mapping to movies
- Booking: movie, theatre, seats, payment method, confirmation ID

### NFRs
- SQLite embedded DB (NFR-DATA-01), file-backed
- Tailwind red/white/black theme
- React Context state
- 2-second payment processing exactly (NFR-PERF-01)

### Release gates RG-01..RG-08 mirror the FRs.
